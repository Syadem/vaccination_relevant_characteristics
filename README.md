# Vaccination Relevant Characteristics

### A shared vocabulary for better vaccination decisions.

Vaccination decisions depend on understanding each patient's circumstances. **Vaccination Relevant Characteristics (VRC)** is a collaborative project that maintains a structured nomenclature of patient characteristics involved in those decisions—giving contributors and developers a common language to build on.

[**Open the admin interface →**](https://admin.vrc.syadem.com/) · [**Explore the full changelog →**](https://syadem.github.io/vaccination_relevant_characteristics/changelog)

## Shared knowledge, ready to connect

VRC brings together a collaboratively maintained vocabulary, multilingual content, and structured data designed for integration into software.

| | What VRC offers |
| --- | --- |
| 🤝 **Collaborative by design** | A shared repository for maintaining and improving patient characteristics relevant to vaccination. |
| 🔗 **Connected to external nomenclatures** | Code mappings connect characteristics to other nomenclatures, supporting interoperability across systems. |
| ✨ **Approachable administration** | A user-friendly interface connected directly to this GitHub repository. |
| 🌍 **Six languages, with room to grow** | English, French, German, Greek, Latvian, and Polish, with the possibility of adding more. |
| 📖 **A traceable history** | A complete changelog makes it easy to follow the evolution of the nomenclature. |
| 🛠️ **Built for integration** | Protocol Buffers exports feed SDKs for TypeScript, Ruby, and Java. |

## Contribute through a friendly interface

The [VRC administration interface](https://admin.vrc.syadem.com/) provides an accessible way to work with the nomenclature, backed by this GitHub repository. It brings a friendly editing experience to a collaborative, version-controlled project.

Want to improve a characteristic, suggest a code mapping, or help extend language coverage? Start with the admin interface or open an issue in this repository to discuss your proposal.

## One vocabulary, multiple languages

VRC is currently available in **English, French, German, Greek, Latvian, and Polish**. Additional languages can be added as the project and its community grow, helping the same shared vocabulary serve more people and applications.

## From shared data to your application

The nomenclature is exported in **Protocol Buffers (protobuf)** format and used to power SDKs in **TypeScript**, **Ruby**, and **Java**. This lets applications in different technology stacks build on the same structured source of knowledge.

Code mappings to external nomenclatures help connect VRC characteristics with the terminology already used in other systems.

## Follow every change

The nomenclature evolves as contributions are made. Browse the [complete changelog](https://syadem.github.io/vaccination_relevant_characteristics/changelog) to explore its history and keep track of updates.
